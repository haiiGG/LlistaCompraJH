# 🛒 Aplicación de Listas de la Compra

##  Descripción

Esta aplicación para dispositivos Android permite crear y gestionar listas de la compra de forma sencilla y organizada. Su objetivo es facilitar la planificación de las compras y permitir que varias personas puedan compartir sus listas para organizarse mejor.

La aplicación está desarrollada con **Kotlin** utilizando **Android Studio**.

##  Funcionalidades

-  **Crear listas:** crear listas de la compra personalizadas.
-  **Añadir productos:** añadir los productos que se necesitan comprar.
-  **Editar listas:** modificar las listas y sus productos.
-  **Marcar productos:** indicar qué productos ya se han comprado.
-  **Compartir listas:** compartir las listas con otras personas para organizar la compra conjuntamente.

##  Tecnologías utilizadas

- **Lenguaje:** Kotlin
- **Entorno de desarrollo:** Android Studio
- **Plataforma:** Android

##  Instalación y ejecución

1. Clona o descarga este repositorio.
2. Abre Android Studio.
3. Selecciona la opción **Open** y elige la carpeta del proyecto.
4. Espera a que Gradle sincronice las dependencias.
5. Ejecuta la aplicación en un emulador o en un dispositivo Android compatible.
